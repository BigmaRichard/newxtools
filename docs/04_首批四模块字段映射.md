# 首批四模块字段映射（客户与联系人 / 订单与发货 / 产品与库存 / 财务）

麦可旺志 Microwants · xtools 优化项目 · 2026-09-11，2026-09-16 按 2026-09-01 版文档修订
依据：《XToolsCRM OPEN API》文档字段说明。枚举列中标注“字典”的取值因公司而异，需以 `scripts/dump_dictionary.py` 导出的结果为准；标注“固定”的为文档给出的固定编码。

约定：R = 读取返回字段，W = 写入可用字段，U = 修改可用字段；“定位”指修改或关联时用于识别记录的字段。

## 1. 客户与联系人

api.update dt=contact，示例带 extend=1；data.id 必填且不能为 0，不能传 cu_sn（所属客户不可改）；只传变化字段。

| 字段 | 含义 | 枚举 / 格式 |

| appellation / department / headship / preside | 称谓 / 部门 / 职务 / 负责业务 | 文本 |
| phone / mphone / mphone_s / fax | 工作电话 / 移动电话 / 备用手机 / 传真 | 文本 |
| email / qq / weixin / wx_name / qq_name | 邮箱 / QQ / 微信 / 微信昵称 / QQ 昵称 | 文本 |
| h_phone / h_addr / h_pst | 家庭电话 / 家庭住址 / 邮编 | 文本 |
| birthday | 生日 | YYYY-MM-DD |
| remark | 备注 | 文本 |
| cr_ty / cr_sn | 证件类型 / 号码 | 固定：1 身份证;2 军官证;3 护照;4 其他1;5 其他2 |
| islinkman | 类型 | 固定：0 联系人;1 主联系人;2 个人客户;3 离职 |
| ext_selN / ext_itemN | 用户画像字段 | 各公司不同 |
| contype / py / ww / skype | 示例中出现、说明未列出 | 联调时确认 |

联系人新增仍通过客户写入接口的 contact 数组；联系人删除无接口。

### 1.3 customerext（客户自定义字段）

读取返回 id、sn 与 ext_ 开头的字段；写入 data 以 sn 或 id 定位，其余为 ext_itemN 等。字段中文名通过 `api.fieldinfo act=dbcn dt=customer` 取得（自定义字段的 name 属性形如 dt_customer_ext_item1）。

### 1.4 cuview（个人客户，仅写入）

name、mphone、department、preside、sex（2 男;1 女）、cr_ty（1 身份证;2 军官证;3 护照;4 其他1;5 其他）、cr_sn、sn、type、period、cu_from、weixin、email、address、remark、ext_itemN。

### 1.5 action（行动记录 / 待办）

| 字段 | 含义 | 枚举 / 格式 |
|---|---|---|
| cale | 类型 | 固定：1 日程;2 待办任务;3 记录;4 *待办任务 |
| subject / content | 标题 / 内容 | cale=3 时标题可省略 |
| type | 行动分类 | 字典 |
| cu_sn | 客户编号 | 读取返回可能为 "[id:6921]" 形式（客户无编号时） |
| con_id | 联系人 ID | 整数 |
| who | 执行人 | part，多人逗号分隔如 "M2,M4," |
| date / endate | 日期 / 结束日期 | YYYY-MM-DD |
| op_id / prj_id / co_id | 机会 / 项目 / 合约 ID | op_id 与 prj_id 只能有一个；三者需与客户一致 |

### 2.5 libout / libin（出库单 / 入库单）

### 3.2 csstree（产品分类）

id、tid（树编号，默认 1）、title、upid（上级节点）、status（0 无下级;1 有下级）。写入返回 id。

### 3.3 prod_alias（产品客制别名）

id、cu_sn（客户编号）、cu_id、pid（产品 ID）、name（客制别名）、sn（客制编码）、memo。写入时 cu_sn 可为编号（文本）或客户 id（数字），name 与 sn 至少一项非空。

### 3.4 libn（外部库存变更）

lib（仓库 ID 数字或仓库名称文本，不存在时自动新建仓库）、prod（产品编码）、num、memo；act=erp_libn。

## 4. 财务

### 4.1 gathering（计划回款）

id、date（计划回款日期）、serial（期次）、money、status（是否回款，字典）、who（所有者 part）、principal（负责人）、cu_sn、co_sn（订单编号）、prj_id、memo。修改以 id 定位，cu_sn 不可传。

### 4.2 gathering_note（回款记录）

| 字段 | 含义 | 枚举 / 备注 |
|---|---|---|
| cu_sn | 客户编号 | 读取返回可能为 "[id:5]" |
| co_id | 订单 ID 或编号 | 可不传 |
| date | 回款日期 | 必填 |
| money | 金额 | 必填 |
| type | 付款方式 | 必填，字典 |
| invoice | 已开发票 | 固定：1 是;2 否;3 无需开票 |
| serial | 期次 | |
| ctype / gtype | 分类 / 类型 | 字典 |
| who / owner | 所有者 part / 创建人 | |
| memo / money_type | 备注 / 币种 | 读取可按 memo 精确匹配 |

写入返回 id。

### 4.3 bill（开票记录，仅写入）与 bill_apply（开票申请动作）

bill：cu_sn、co_sn 或 co_id、type（票据类型，字典）、tax_rate、content、money、billsn（发票号）、money_type、money_rate、date、serial、who、cu_sub、sthk（是否回款）、stjh（回款计划）、sendcode、mphone、address、memo；返回 id。
bill_apply：act=kaipiao，data={id（开票申请 ID）, billsn}。开票申请本身的读取接口未在文档中提供，需与 XTools 确认。

### 4.4 pay_plan（付款计划）

id、date、serial、money_type、money_rate、money、money_memo、who、status、pu_id（采购单）、cu_sn（供应商编号）、ctype、type（付款方式）、exp_date、pay_com、rec_com、bank、acc_no、others、memo、owner、prj_id、bill_num。

### 4.5 purchase（采购单）

主表：id、title、cu_id 或 cu_sn（供应商）、No.、date、eta、type、status0、status（入库状态）、lib、address、who、money_type、money_rate、money、amount_before_tax、backsum（已付）、return_yn、confirm、ref_cu_id、ref_co_id、prj_id、bl_flag、sendcode、is_zhifa、jN。
明细 puritem：id、prod、sku、num、price、money、backnum（已入库）、memo、tax_rate、tax_money、un_price_tax、prod_name、model、batchnum。写入用 extend=1。

### 4.5a purreturn（采购退货单，2026-09-01 版新增，只读）

字段与 libreturn 对应：id、subject、cu_sn（供应商编号）、pu_id（采购单 ID）、status（0 待处理;2 执行中;3 结束;4 终止）、ra_who、ra_date、lib、memo、date、who、who_name、return_no、st_libout（0 待出库;1 生成出库单;2 部分出库;3 全部出库;4 退货完成(无出库)）、st_hk（0 未退款;1 部分;2 全部）、hk_sum、money、money_type、money_rate、one_select、org_id，明细 purrtnitem[{id, pid, rnum, rprice, rsum, nout（已出库数量）, reason, memo}]。

### 4.6 cost / costdetail（批单报销 / 费用明细，读取为主）

cost：id、number、type、date、sum、baox_st1（0 未报销;1 部分;2 已报销）、baox_my1、b_trip_id、aprv_st、aprv_nr、baox_my、baox_st、who、part、aprv_status（0 非审批;1 未提交;2 已提交;3 审批中;4 同意;5 否决;6 已撤销）、memo、costdetail[]。
costdetail：id、money、num、type、bill_type、bill_tax、human、cu_sn、date、name、reimburse（1 -;2 已报销）、use、memo、b_trip_id、cost_id、action_id、confirm、who。
