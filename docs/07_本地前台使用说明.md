# 本地前台使用说明（浏览器查看 XTools 镜像数据）

麦可旺志 Microwants · xtools 优化项目 · 2026-09-18

## 1. 是什么

一个只在本机运行的网页前台：读取 P0 只读镜像 `data/xtools_mirror.sqlite`，在浏览器里查看经营总览、订单、客户、应收与回款、工作日志。它不连接 CRM，也不向镜像库写入；数据随同步任务每 30 分钟更新一次，页面右上角显示“数据截至”时间。

只监听 `127.0.0.1`，只有这台 Mac 上的浏览器能打开；同事需要看时另行部署（见第 6 节）。

## 2. 安装与打开

首次安装为常驻服务（退出或重启登录后由 launchd 自动拉起），然后在浏览器打开：

```
cd ~/newxtools && .venv/bin/python scripts/install_launchd.py --web && sleep 3 && open http://127.0.0.1:8765
```

服务启动时会检查镜像库结构并补建查询索引（0.4 起，约 1 秒；若同步任务正在写库会先等待其提交）。日常直接打开 http://127.0.0.1:8765 即可；可以在浏览器里加为书签或“添加到程序坞”。

| 目的 | 命令 |
|---|---|
| 临时在终端前台运行（调试） | `cd ~/newxtools && .venv/bin/python scripts/web.py` |
| 换端口 | `cd ~/newxtools && .venv/bin/python scripts/install_launchd.py --web --port 8800` |
| 卸载常驻服务 | `cd ~/newxtools && .venv/bin/python scripts/install_launchd.py --web --uninstall` |
| 查看服务状态 | `launchctl list \| grep xtools-web` |

日志：`logs/web.log`（接口耗时、错误）、`logs/launchd.web.out.log` / `launchd.web.err.log`。

## 3. 页面

| 页面 | 内容 | 说明 |
|---|---|---|
| 总览 | 本月 / 今年订单额与回款额（含同比）、执行中订单、未回款与逾期；按月订单额与回款额柱图（可切换年份，悬停显示上年同期）；年度订单状态、新近订单；客户 / 业务员 / 产品 Top 10 | 金额统计不含“意外中止”订单 |
| 订单 | 按单号 / 主题 / 客户名称、日期区间、状态、业务员、发货状态筛选；每行显示已回款金额与发货单数 | 点行打开订单详情：明细、回款记录、计划回款、发货单、出库单、相关行动记录、其他字段 |
| 客户 | 按名称 / 简称 / 编号、所有者、生命周期、类型、阶段筛选；每行显示订单数、订单额、末次订单日期、回款额、联系人数 | 点行打开客户详情：联系人、历年订单额、订单、未回款计划、回款记录、行动记录 |
| 应收回款 | 计划回款：未回 / 逾期 / 已回，账龄分布（未到期、≤30、31–90、91–365、>1 年），按业务员汇总；回款记录：按月柱图、按业务员汇总、明细 | “部分回款”按计划金额全额计入，CRM 未提供已回部分金额 |
| 工作日志 | 行动记录（电话 / 拜访 / 微信记录等）：日期区间、人员、类型、关键词；按人员、按类型、按日统计 | 点“按人员”中的姓名只看此人 |

详情抽屉里的客户名、订单号可以继续点开，右上角“返回”回到上一层。

## 4. 数据口径

| 项 | 口径 |
|---|---|
| 订单金额 | contract.sum；币种非 RMB 时在金额旁标注币种，汇总时未折算 |
| 订单关联客户 | cu_sn 为 "[id:N]" 或客户编号 sn；出库单 cu_sn 为纯数字客户 id |
| 已回款 | 回款记录（gathering_note）按 co_id = 订单 id（或订单编号）汇总 |
| 应收 | 计划回款（gathering）状态为“未回”或“部分回款”的计划金额；逾期 = 计划日期早于今天 |
| 人员 | 订单 / 回款记录的 who 为姓名；客户所有者、计划回款、出库单的 who 为 part，行动记录 who 为 ",M1,M2," 形式；均按人员表（crm_user）换算为姓名；离职人员姓名带“(离职)” |
| 同比 | 今年 1 月 1 日至今天，与上年同一区间比较 |
| 其他字段 | 详情页“其他字段”列出原始 JSON 中未进规范化表的非空字段（如自定义字段 j1…），名称取自 CRM 字段中文名 |

## 5. 接口（供其他系统读取）

前台的数据接口可直接给本机其他程序调用，返回 JSON（UTF-8）：

| 接口 | 参数 |
|---|---|
| `GET /api/meta` | — |
| `GET /api/overview` | year |
| `GET /api/orders` | q、from、to、status、who（part）、type、st_send、customer_id、sort（amount / date_asc）、page、size（≤500） |
| `GET /api/orders/{id}` | — |
| `GET /api/customers` | q、owner、life、type、cu_status、sort（amount / orders / created / name）、page、size |
| `GET /api/customers/{id}` | — |
| `GET /api/receivables` | status（open / overdue / done / all）、who、customer_id、from、to、q、sort、page、size |
| `GET /api/receipts` | from、to、who、type、customer_id、q、page、size |
| `GET /api/actions` | from、to、who、type、cale、customer_id、q、page、size |

也可以直接读 SQLite（视图 v_contract、v_receipt、v_customer_overview 等，见 docs/06）。

## 6. 局域网访问（暂未启用）

需要同事访问时，可用 `scripts/web.py --host 0.0.0.0` 监听本机各网卡，但前台没有登录与权限控制，开放前应先加一层账号密码（例如用 Caddy / nginx 做反向代理并配置 basic auth），并限制在公司内网。外网访问需要另行部署服务器与同步程序，方案另议。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 页面提示“无法连接前台服务” | 服务未运行：执行第 2 节安装命令，或 `launchctl start com.microwants.xtools-web` |
| 右上角提示“超过 2 小时未更新” | 同步任务未跑：看 `scripts/sync.py --status` 与 logs/sync.log |
| 数字与 CRM 不一致 | 先看“数据截至”时间；订单表每周全量一次才会体现删除；金额口径见第 4 节 |
| 页面很慢 | 看 logs/web.log 中每个接口的耗时；正式库上各接口通常在 100 毫秒内。重启服务会重新检查索引：`launchctl kickstart -k gui/$(id -u)/com.microwants.xtools-web` |
| 端口被占用 | `install_launchd.py --web --port 8800` 换端口 |
